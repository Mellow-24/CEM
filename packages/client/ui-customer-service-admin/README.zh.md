# @deepseek-ai/dsh-client-ui-customer-service-admin

[English](README.md) | 中文

澳门电力智能客服运营后台。独立的 `/customer-admin` URL 提供收口后的澳电品牌管理门户，原有全屏 Settings 后台保持视觉和路由不变。两套界面使用相同 store 与 Host 回调。独立门户提供工作台、智能体与渠道、当前知识库、发音与词库、会话中心、质检与评测、报表与大屏；对话编排、模型配置和提示词演练仅保留在旧后台。默认 `zh` locale 使用繁体中文；客户消息、历史回答、知识摘录、文件名称和标识码保持记录时的来源语言。

## 运行数据与配置工作区

显式选择的真实视图通过 `ctx.remote.customerServiceAdmin` 读取总览、文档目录、检索、暂存上传和问题案例台账。页面呈现加载、空结果、错误与重试，不用模拟数据填补失败。模型和预设入口进入现有配置页面。会话中心默认使用权威 `useSessions` 历史，排除空白与 subagent 会话。Host 质检读取器检查已记录的消息、工具和耗时，不恢复原 agent（智能体），也不展示模型内部推理。快照显式刷新，查看其他历史不会切换当前客服会话。

独立门户只在 `/customer-admin` 占用 root slot，并通过私有 keyed 子 slot 呈现七个业务页面。URL fragment 保留直接页面选择，例如 `/customer-admin#knowledge` 与 `/customer-admin#sessions`；指向已屏蔽页面的 fragment 会回到工作台。界面沿用 `/customer` 的澳电橙红与黄色品牌风格，提供返回客服端的入口，并自行控制浏览器标题。工作台和“当前知识库”直接打开真实运营数据。独立门户的总览、知识和质检视图不显示 Provider 标识，但保留检索设置与运行结果。原有 Settings 注册继续供旧运营外壳使用。

真实 TXT/Markdown 上传通过修订检查进入 Host 独立暂存目录，不允许覆盖。RAG/Wiki 检索返回依据而不生成回答。没有真实知识发布、删除或晋升入口。索引就绪不表示模型端点健康，证据排序分数不表示回答准确率。

配置工作区使用插件创建的 root 作用域 `defineStore`，与所有真实数据回调分离。当前浏览器应用内切换页面、关闭后台均保留草稿；刷新页面或确认“重置工作区”后恢复初始数据，包括编辑器中未保存的输入。“工作区设置”收纳数据说明和重置入口，简洁的草稿、验证集、未接入标签区分未接通功能和运行服务。工作区操作不会写入正式设置、上传文件、调用模型或语音服务，也不修改 Session。

- 渠道提供开场白、语言、启用开关、文本电话预览和未保存提示。
- 三个固定五节点流程模板支持拖动、键盘移动、修改名称及正常后继、图校验，以及正常／无记录／超时逐步模拟，不执行真实业务查询或转人工。
- 知识加工接受单个不超过 256 KiB 的本地 TXT/Markdown，按段落切片，支持编辑切片、子串搜索及完成审核，但不发布。共享操作要求非空查询命中切片后才能推进，明确勾选审批后才能完成审核。修改内容或查询会使验证及审批失效；这些状态跨页面保留。文件只留在浏览器内存。A/B/C 回答编辑器提供固定话术、必需业务占位符与知识回答策略。
- 发音管理将按语言执行的通用规则与精确词条纠偏分开。规则工作区根据所给参考表展开澳门地址及银行缩写，并在仅供合成的文本副本上规范化楼栋号、日期、金额与百分比。运营人员可按语言和类型筛选，启停草稿规则，并对比显示文本、播报文本和命中规则。粤语精确词条保留 16 个可搜索条目及版本化复核行为。两种预览均为文本，不合成音频。
- 会话与质检使用独立查看状态和 Host 持久化记录，不使用配置样例。搜索组合标题／标识／推断意图、预设、质检状态、分数阈值及十条分页。切换页面保留筛选；浏览器刷新重置权重草稿，但每次任务保留自身准确权重。
- 报表按同一批虚拟会话聚合，支持渠道筛选和全屏展示。真实记录缺失的渠道、语言和发音版本保持未知。

## 运营验证流程

会话中心 → 查看详情 → 选择全部或单个轮次 → 开始质检。六维评分展示简短理由、建议和证据按钮。“执行过程”通过 `operations.trace` 呈现现有轨迹表；“检索依据”展示原始工具结果，不重新检索。“质检与评测”列出持久化任务并提供权重草稿。人工复核必须填写依据，可单独调整人工总分，支持建立、验收或重开整改。刷新后历史仍可查看，缺失证据不虚构评分，失败后可创建新任务。

## 模型体验

### 质量检查

#### 模型看到什么

配置演练内容不进入模型。显式 `startQuality` 质检使用选定的历史证据调用 [Host 评估器](../../host/customer-service-admin/README.md#quality-evaluation)。读取、筛选、查看轨迹与人工复核不调用模型，也不改变已生效的 Agent 组装。

#### Token 影响

每项获准执行的质检任务消耗一次独立且有界的评估请求。浏览后台不会为客户对话增加 token。

#### KV Cache 影响

质检请求独立执行，不复用或修改客户对话的请求前缀。

## 已知限制与暂缓事项

- 设置演练不持久化；质检记录在本机持久化，但没有多用户授权或经认证的复核人身份。繁体中文是澳门运营人员的默认 locale，同时保留可选的葡语和英语词典。
- 演练控件未接通渠道、发音规则发布、合成试听、业务系统或经审核的真实发布。接通时必须在回答生成后执行按语言选择的规范化器，保留显示文本，再为选定的 TTS Provider 编译精确别名或音素。质检整改记录运营人员的决定，不发布修复。
- PDF/Office 解析、OCR、任意流程节点与分支、音频对齐历史需要独立能力。
- Remote 数据是时间点快照，权威 runtime 负责会话目录恢复；真实问题案例台账仍为只读。
