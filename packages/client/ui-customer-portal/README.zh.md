# @deepseek-ai/dsh-client-ui-customer-portal

[English](README.md) | 中文

这是 `/customer` Web 路由使用的澳电客户会话外壳。该包只在这个路径替换根 slot，因此 `/` 上的标准 DeepSeek Harness 运营界面保持不变。它复用现有浏览器 Session 运行时、agent 预设选择、流式事件投影、取消操作和浏览器语音运行时。

门户会在当前 Workspace 中激活或创建空白 Session，并在第一条提示词之前选择随附的 `macau-customer-service` 预设。每次访问都会先显示开场白和分组推荐问题。固定高度的历史侧栏按最近活动顺序列出采用同一预设的非空、未归档根 Session，每页最多显示八条。选择记录会打开其权威历史，「新对话」会回到空白 Session，「删除对话」在确认后将记录归档并从客户历史移除，同时保留 Session 日志供后台质检。正在回复的 Session 不能删除。客户路由不提供独立 `/customer-admin` 运营管理门户的入口，也不嵌入管理控件。客户视图不显示其他预设、subagent 工作、工具调用、推理、配置控件和 Workspace 导航。

初始状态显示客服开场白，以及从已审核澳门客服知识语料的准确 FAQ 标题中选取的繁体中文问题，包括账单与缴费、供电与合约、停电与安全、电动车与应用。手工输入或选择推荐问题都会进入普通 Session 提示词路径。客户投影会隐藏调用工具的助手步骤和第一步局部文本，因此检索前的过程说明不会成为客户消息。从本地提交、模型准备到隐藏的知识检索，页面会持续显示进度卡，回答正文开始流式输出后由正文替换；未调用工具的第一步直接回答则会在完成后显示。语音输入使用标准语音控制器录制一段话并把转写结果放入输入框。标题栏的通话控件复用标准会话界面的连续识别、打断、预制开场白和逐句合成控制器；提交的文本和回答仍是普通 Session 历史。

页面从澳电官方网站加载正式 CEM 标志。需要离线运行的部署应提供经批准的本地副本，并更新组件中的资源 URL。

## 模型体验

该页面通过手工输入、推荐问题和语音转写控件提交普通 Session prompt，从而间接影响模型；所选 agent 预设负责所有模型可见的 system prompt、工具和回答策略。

#### KV Cache 影响

问题提交后会像普通用户消息一样扩展 Session 历史；门户自身不增加 prompt 内容或缓存材料。

## 已知限制与延后工作

- 客户路由要求已有 Workspace，因为共享 Session 运行时会把每个新 Session 关联到一个 Workspace。
- 语音输入和通话要求所选预设提供转写与合成 profile；服务不可用时控件会明确提示，不会回退到浏览器语音 API。
