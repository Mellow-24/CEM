# `@deepseek-ai/dsh-client-ui-mobile-chat`

[English](README.md) | 中文

基于现有 Host、Session、agent（智能体）预设及[浏览器语音运行时](../ui-voice/README.md)的澳电品牌手机聊天界面。Node 端仅提供配置；浏览器端独立拥有根节点、Session 内的草稿存储、推荐问题、消息列表、历史抽屉、录音控件及可收起的通话页面，不在桌面 `/` 或 `/customer` 挂载。

## 配置与入口

`entryMode: preview` 启用 `/mobile.html?ui=cem-chat`；`entryMode: default` 同时启用 `/mobile.html`。`/mobile.html?ui=legacy` 始终保留原手机根节点。部署入口由 web bundle 配置决定，本插件不重定向浏览器，也不注册 service worker。

`defaultPreset` 选择初始客服 agent，且必须出现在 `servicePresets` 中。后者将服务选择器与历史记录限制为配置的客服 agent。`language` 选择通话开场白与语音语言。默认值分别为 `macau-customer-service`、两个澳门客服预设和 `yue`。工作区缺失、预设不可用或恢复失败时显示错误并允许重试，不用模拟回答替代 Host 故障。

打开 Session 时，通过 Host 的显式 id 创建操作恢复持久化的身份、工作区和预设，然后再请求语音能力。浏览器只恢复它之前选择的 Session id；没有本地标记时，会创建空白对话，不采用 Host 全局当前 Session。连接重置后，手机界面先使已缓存的语音权限失效，再恢复该精确 Session，最后重新加载语音能力。更换服务会打开空白对话，不改写已有历史的预设。浏览器存储只记住选择的 Session id；消息仍由 Host 日志保存。文字草稿与未发送的录音不跨页面刷新持久化。

## 交互与媒体

推荐问题与文字消息使用普通 Session 提交流程，流式显示真实助手回答。录音支持按住说话、上滑取消以及点击操作。识别文字加入最新草稿，等待用户明确点击发送。较晚返回的发送结果不会清除用户刚输入的新内容。不伪造语音消息气泡：录音不会保留用于回放。

通话与聊天使用同一个 Session。返回聊天只收起通话，不释放媒体；明确挂断、切换 Session 和离开页面时释放采集与播放。静音停止发送 PCM 并丢弃未完成的识别内容；“我要說話”中断本次回答但保持识别连接。Host 的麦克风处理和 VAD 配置保持不变。

固定通话布局以文字为主，状态圆环保持小尺寸，通话按钮始终可见。当前通话的欢迎语、用户话语和已生成回答都保留，包括被打断的文字。文字区域可以滚动，但不显示滚动条轨道；默认跟随新内容，用户上滑回看时暂停跟随，点击“回到最新對話”恢复跟随。收起通话保留阅读位置。无空格的连续编号也会换行。共享控制器拥有这份临时通话记录，只有已提交消息在 Host Session 中持久化。圆环与录音波形动画表示状态而非麦克风音量，并遵循减少动态效果偏好。

通话文字直接显示在页面上：客服靠左、用户靠右，保留说话人名称，不添加外围卡片、字幕标题或消息气泡。

Host 的补充问题支持逐题选项及自定义文字回答。系统操作授权可以在此拒绝；授予权限需要到原应用的完整权限页面查看。任何权限都不会自动授予。

颜色由主题包中的 `[data-cem-mobile="chat"]` 调色板管理；组件样式使用独立 CSS Modules。用户提供的 logo 从 `/cem-mobile/logo.jpeg` 加载。页面适配可视视口与安全区域，不添加模拟的手机状态栏。

## 模型体验

间接影响：文字、推荐问题及确认后的语音文字使用普通 Session 提交，通话使用 Host 语音包现有的已记录通话指令；界面导航、波形动画和草稿编辑不会增加模型内容。

#### KV Cache 影响

沿用普通仅追加会话行为；界面不改变提供方请求或缓存策略。

## 已知限制与暂缓工作

- **设备验收** — 自动化 Chromium 采集与回放无法证明特定安卓浏览器、扬声器、麦克风、回声路径或证书信任正常。麦克风需要 HTTPS 和授权，浏览器仍可能在后台暂停页面。
- **仅 AI 通话** — 通话按钮启动浏览器 AI（人工智能）对话，不拨打 PSTN 电话，也不转接人工客服。
- **共享部署** — 本地 Session 恢复可避免误采用另一浏览器的当前对话，但界面隔离不等于独立的客户授权、历史可见性、配额或数据租户隔离。局域网免密属于开发配置，不是正式环境的鉴权方案。
- **权限详情** — 管理类工具的授权仍在原应用完成。手机客服对话应使用适当限制权限的 agent 预设。
