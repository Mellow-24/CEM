# Agent Note: 澳电客户会话门户

Status: implemented

[English](2026-09-12-cem-customer-conversation-portal.md) | 中文

## 问题

澳门客服预设和运营管理台运行在通用 agent 界面中，其中的导航、开发者控件和产品标识不适合公开的客户入口。与后端断开的视觉原型虽然外观正确，却无法展示真实的 Session 连续性、流式回答、取消操作或语音转写。

## 决策

`@deepseek-ai/dsh-client-ui-customer-portal` 在 `/customer` 提供面向客户的 CEM 外壳。其客户端插件只在该 pathname 生效时注册一个替代 `root` 占用项。`/` 上仍只有标准根占用项，因此既有运营界面和管理流程保留当前行为与 URL。

客户外壳复用现有 Session 运行时和 API 连接。它会使用当前空白 Session，或通过当前 Workspace 连接一个空白 Session，然后在第一条提示词之前选择 `macau-customer-service`。路由在新一轮对话开始前始终显示客户开场白和分组推荐问题。固定高度的历史侧栏从共享 Session 列表中派生最近的非空根 Session，排除 Workspace 归档集合中的 id，仅接纳相同客服预设，每页最多渲染八条。它会打开所选的权威 Session，不会把消息复制到门户状态。客户确认删除后会调用现有 Workspace 归档操作：该记录从客户历史消失，持久日志仍供后台质检；正在回复的记录不提供该操作。用户提示词、取消操作、持久历史、助手局部文本和最终回答都沿用标准会话界面的 Host 路径。客户投影只显示用户提示词与面向客户的回答正文。包含工具调用的已完成助手步骤保持隐藏，第一步局部文本也会隐藏，以免在工具调用到达前短暂闪现；后续回答阶段的局部文本保持可见，未调用工具的第一步直接回答则会在完成后显示。工具、检索过程说明和推理记录仍保留在权威 Session 日志以及[运营管理台](2026-09-04-customer-service-admin-console.md)中。

客户初始状态采用 CEM 视觉标识、开场白，以及主题在已部署澳门知识语料中有已审核条目的繁体中文分组问题。`dsh-client-ui-voice` 在既有 Session 级录音和[语音通话控制器](2026-09-03-customer-service-voice-calls.md)之上提供 Cordis 客户端服务。门户通过该服务为当前 Session 请求一个运行时：输入框麦克风录制并转写一段可确认的话，标题栏通话按钮则呈现连续识别、打断、预制开场白播放、同步字幕和逐句合成。两种模式都使用预设授权的 Host profile，并在客户 Session 离开页面时释放媒体资源。

Web bundle 声明 DashScope 对话提供方的 Qwen 推理方言，并显式选择 `off` 推理强度。工具选择和回答阶段因此不需等待提供方默认隐藏推理即可流式输出。RAG 查询 embedding、候选数、向量阈值、重排请求、重排阈值与最终结果顺序保持不变；该延迟选择不会替换或削弱知识检索。

[深绎未来标识决策](2026-09-05-shenyi-future-product-identity.md)继续约束运营产品。此处的 CEM 标识是路由专用的客户展示，不会反转该决策，也不会重命名内部包、wire id、settings namespace 或运营外壳。

## 曾考虑的替代方案

否决**独立静态应用**，因为它会重复 Session 传输并可能偏离真实流式行为。否决**在所有 pathname 上替换标准根节点**，因为这样会移除部署仍需使用的运营流程。本次交付否决**第二个服务器和前端分发包**，因为现有 SPA fallback 已能让 `/customer` 拥有独立 URL，同时共用完全相同且同源鉴权的 API。否决**在门户中重新实现语音请求**，因为这样会绕过已测试的浏览器媒体生命周期，并偏离标准通话行为；语音包改为在相同控制器之上提供客户端服务。

**保留对话提供方的默认推理模式。** 不采用，因为已记录的客户话轮显示，知识检索完成后的等待主要由隐藏推理构成。该路由依靠已审核的检索和重排链提供证据，显式非推理模式在保留这条链的同时，可更早开始面向客户的回答流。

## 后果

客户 URL 不含开发者或运营外框，也不暴露 `/customer-admin` 入口；运营人员直接访问该路由。每次访问都从空白对话展示开始；客户可从有界侧栏重新打开或归档以往客服 Session，已提交的客户对话仍无需复制即可出现在质检中。检索过程说明仍可供内部检查，但不会作为独立客户气泡显示。该路由要求已有 Workspace，目前固定使用 `macau-customer-service` 预设。语音控件要求该预设提供转写、实时识别和合成 profile。正式标志是远程 CEM 资源，离线部署需要经批准的本地副本。显式的非推理回答配置降低首段可见回答的延迟，代价是该客服路由不使用隐藏推理；检索与重排仍为回答提供证据。client 测试和装配 Web 浏览器证据覆盖路由级组合、全新开场状态、有界且筛选后的历史导航、客户端删除、知识库支持的推荐问题、语音控件、提示词投递、隐藏工具步骤说明，以及运营品牌和入口均不出现。
