# Agent Note: 混合式通话打断

Status: implemented

[English](2026-09-30-hybrid-call-interruption.md) | 中文

## Problem

明确命令规则会漏掉自然纠正和追问，而将所有识别语音视为打断又会接纳附和及背景聊天。辅助推理不能拖慢普通回答、提前停止播放，或取消后续回答。

## Decision

浏览器在本次回答期间拒绝空文字、单字及独立附和。移除礼貌前缀后，单独的“停”仍不打断。明确停止命令使用本地规则；其他完整插话候选使用可选的 Host 配置分类，期间音频继续播放。分类上下文包含近期问题和实际开始播报的句子，而不是尚未播放的生成文字。

Host 只发起一个有上限、关闭思考的请求，不检索或重试。超时、无效输出、取消及容量不足都表示继续播放。候选身份、回答身份及取消信号共同约束接纳。仅噪声起声保留完整候选；实际新文字替换其请求并保留相邻片段。分类耗时计入现有合句间隔。

完整辅助请求记录为 `speech/interruption-request`，标记 `ignorable: true`。它不产生对话消息，旧读取器可跳过而不改变历史重建。不修改 ASR、回答语言、RAG、TTS 或对话提示词设置。

此决定部分取代[明确意图的通话打断](../bug-fix/2026-09-29-explicit-call-interruption.md)中的纯规则接纳；其完整回答筛选、拒绝输入临时保存、取消归属及续接依据继续有效。

## Alternatives considered

**仅使用规则。** 可预测且快速，但自然纠正依赖具体句式，而不是意图。

**分类所有临时转写。** 重复请求消耗配额，与变化中的文字竞争，并可能影响普通回答容量。只有经过筛选的完整插话候选才进入推理。

**先停止，拒绝后恢复。** 附和与背景语音会产生可听到的停顿，因此播放持续至肯定意图得到确认。

## Consequences

自然插话增加 ASR 最终识别及辅助推理延迟；普通问题及明确本地命令不依赖分类器。文字无法识别说话人，保守超时也可能漏掉真实插话。生命周期单测、真实提供方分类、新客服及移动入口的完整浏览器回放、旧读取器日志回放覆盖接纳、取消、播放连续性及回退安全。
