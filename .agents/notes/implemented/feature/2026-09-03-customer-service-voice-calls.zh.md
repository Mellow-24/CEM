# Agent Note: 基于持久化文字的客服语音通话

Status: implemented

[English](2026-09-03-customer-service-voice-calls.md) | 中文

## Problem

澳门客服预设需要实时语音提问与可打断的回答，同时保留知识工具、语言规则和可恢复的会话历史。

语言与音色遵循每轮已记录的 `response-language/resolved`。默认粤语问候，自动模式跟随提问语言，手动选择优先。公司 MiniStream 提供方为粤语使用算法微调的 `mailinlin` 预置音色，并为普通话、英语和葡语使用对应预置音色；48 kHz 单声道 MP3 帧到达后立即转发。Qwen 继续负责识别。历史播放使用原轮语言。ASR 若把粤语规范化为普通书面语，文字检测无法保证恢复方言。

## Decision

浏览器在全屏通话期间持续开启由部署配置的麦克风。Host 将回声消除、环境降噪和自动增益作为显式通话设置提供给浏览器。AudioWorklet 通过按顺序的 Host 上传发送 100 毫秒、16 kHz 单声道 PCM16 音频帧。Host 持有的 Qwen WebSocket 配合服务端 VAD 返回开口、临时字幕和最终转写。浏览器在当前临时结果之前保留已完成的 ASR 片段；若在配置的合并宽限期内继续说话，则取消待提交操作，宽限期结束后才把所有已完成片段以换行连接成一条用户消息，通过普通 Session 提交。回答期间开口会取消当前回答并停止播报。合成与播放期间持续收音。只有具备流式能力的配置显示通话按钮；独立麦克风按钮仍提供完整录音输入。

固定欢迎语 WAV 在 Host 启动时加载，浏览器按所选语言预加载。点击时同步调用音频播放，同时连接识别服务。欢迎语不产生模型请求或持久化的助手消息，避免在模型步骤之外伪造助手事件。[欢迎语收音保护](../bug-fix/2026-09-07-protected-call-greeting.md) 规定开场例外：识别事件不能打断欢迎语，麦克风上传只在它结束后开始。用户文字与客服播报使用带标识的独立字幕。客服句子只会在其 `onPlaying` 事件触发后加入字幕，使可见文字不会领先音频；打断后已开始的字幕仍然保留。`call.playbackRate` 在浏览器中保持音调地调整速度，客服默认 1.15 倍，不向流式提供方发送其不支持的语速参数。最终问题与已提交回答在挂断前已持久化。临时字幕和原始音频不持久化。被打断的音频回答仍在历史中保留已提交文字，这不代表用户实际听完了全部音频。

通话观察单个空闲到完成的区间，不具有每条提问的因果回执。其基线包含先前的轮次结束事件，防止上一轮回答提前结束下一轮提问。其他用户输入会结束通话，但不取消其他工作。挂断、Session 变化和传输中断会取消媒体与本通话拥有的工作；有界音频和事件队列终止慢连接，避免重放过期音频。

作用域转写服务暴露可选的流式操作。Qwen 提供方管理 WebSocket 认证、协议验证、建立连接和通话时长限制，以及异步连接关闭。Web Consumer 授权精确的实时根 Agent，每个 Session 仅接入一个识别器，并在读取请求体后检查通话令牌与上传序号。路由默认仅允许 loopback；显式 trusted-host 仍要求部署访问控制。

[浏览器语音设计](2026-08-31-browser-speech-and-authorized-voice-preset.md) 中的服务分离与作用域授权仍有效；手动播放使用已提交文本，通话允许校验后的日志文本句子。

通话在句末标点、达到配置最小长度后的逗号类停顿以及长度上限处分段，并预加载下一段。排版换行保留在当前片段内，Host 校验精确的日志前缀后再合并其中的空白。内部安全切分沿用原文间隔并显示在同一段字幕中，不会额外产生可见换行。客服部署允许至少 12 个字符的片段在逗号类停顿处提交，并把无标点片段限制为 72 个字符。不含 Unicode 字母或数字的片段保留在持久文字中，但不发送给合成服务，避免标点或末尾 emoji 成为无效的独立 TTS 请求。MiniStream 按语言与音色保留一条已完成的鉴权连接 60 秒；后续串行操作会复用该连接，二进制音频帧不携带 request id，因此并发生成使用独立连接。取消、失败、下次获取连接时检测到凭据变化及提供方卸载会关闭受影响连接。单句合成或播放失败会取消当前回答剩余的音频并显示提示，识别连接保持可用以接收下一条问题。Host 从授权 Session 的日志按 turn、step、block 与前缀哈希恢复文本，拒绝推理与改写后的过期前缀。两个客服预设使用 `threshold: 0.75` 和 250 毫秒静音窗口的 Qwen 服务端 VAD，再在最终 ASR 片段后保留 150 毫秒浏览器合并宽限期。浏览器输入开启回声消除和环境降噪，同时关闭自动增益，避免低电平环境声在进入 VAD 前被放大。该设置以约 400 毫秒完成交接，同时过滤更多背景声。它们关闭语言插件的整段校验缓存，保留语言提示；其他预设默认仍启用整段校验。关闭校验时，response-language 还会在其他上下文之后记录本步骤的精确语言提示，要求模型在每次工具返回后仍遵循解析后的字形和语体，避免因完整文本无法撤回而直接把繁体或粤语证据当作普通话答复。

实时连接会把部署配置的 `responseInstructions` 安装为精确实时 Agent 的作用域运行时上下文，并在连接关闭时移除贡献。Agent loop 在模型请求前记录解析后的上下文快照；挂断后的下一次模型步骤记录清除后的快照。澳门部署要求通话轮次先说直接答案，使用适合朗读的纯文本短句，省略阅读型格式和证据编号，最多选取三个相关知识要点，并用追问承接长流程的剩余内容。Wiki persona 继续要求每项事实都有证据支持，仅在该通话上下文生效时省略引用标记。文字轮次保留原有表达方式和引用。

## Alternatives considered

**每帧单独等待一次 HTTP 往返，或允许无限积压。** 每帧音频为 100 毫秒，串行单帧上传的请求往返一旦超过该间隔，就会持续积压过期音频。浏览器将待发帧合并到下一次上传，同时保留顺序。Host 每次接受 1–20 个完整帧，逐帧转发以遵守提供方缓冲限制，并拒绝重叠上传以防止交错。[上行积压设计](../bug-fix/2026-09-14-recoverable-voice-uplink-backlog.md) 将两秒的单次请求上限与部署方配置的总积压时长分开，使短暂停顿能够恢复，同时仍对持续阻塞保持上限。

**挂断后写历史。** 否决，因为中断会丢失已接受内容，通话期间还需要第二份模型历史。

**直接向对话模型发送音频。** 否决，因为现有文字预设拥有知识检索和证据要求。

**同时挂载 Qwen 与 MiniStream 合成 profile。** 否决，因为语音服务在合成前要求解析出唯一 profile。单个 MiniStream profile 按解析后的语言选择预置音色，仅粤语使用 `mailinlin`。

**等待完整回答后再播报。** 否决，因为会把整轮生成时间加入每次通话等待。逐句播报接受已听内容无法撤回的限制；打断会取消当前音频与下一句预加载。

**只用浏览器音量阈值判断开口。** 对连续通话否决，因为轻声与背景噪声需要识别侧断句；Qwen VAD 管理可配置的停顿阈值。

**每次通话重新生成欢迎语。** 固定欢迎语无需等待模型轮次或额外服务请求。预制音频需在部署时更新，以换取稳定的启动时间。

## Consequences

两种检索策略共用一个通话 UI。浏览器回声消除降低外放反馈，但不能保证所有环境中的打断准确率；声学条件需要部署验证。单元测试覆盖取消完成、过期合成、停顿分段、合成失败隔离、不可播报的末尾片段、竞争输入、提供方映射、串行连接复用、上传顺序与资源清理。浏览器测试使用回放的外部提供方覆盖问候、持续收音、播报打断、连续回答、全屏尺寸与持久历史。凭据控制的真实 Qwen 测试验证按实时节奏输入 PCM 可返回开口、临时文字和最终转写，无需显式提交。另一项凭据控制的 MiniStream 测试验证串行 `mailinlin` 操作复用同一连接，同时保持渐进 MP3 输出。

## Supersession

**部分被取代。** [通话历史及续接](../bug-fix/2026-09-14-call-history-and-continuations.md)以识别文字确认打断、850 毫秒续说窗口和明确的原问题续接，取代仅开口即打断及 150 毫秒交接。手机通话界面跨轮次保留当前通话文字。

**部分被取代。** [通话回复可见与 TTS 降级](../bug-fix/2026-09-14-visible-call-replies-and-tts-fallback.md)取代了由 `playing` 控制字幕、单合成 profile 和并发 MiniStream 测试的决定。已生成 Session 文字会立即进入通话字幕，受限的下一句只在当前音频开始产生可听声音后准备；MiniStream 仍为首选，音频开始前发生故障时由配置的 Qwen profile 接续。
