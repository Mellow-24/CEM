# Agent Note：深绎未来产品标识

Status: implemented

[English](2026-09-05-shenyi-future-product-identity.md) | 中文

## 问题

澳门电力智能客服演示需要一套与底层 harness 明确区分、且前后一致的产品标识。只改浏览器标题会让浏览器外壳、导航、空白会话页、模型名称和 PWA 安装界面仍然显得割裂。

## 决策

面向用户的 Web 产品名称采用「深绎未来」（英文为 Shenyi Future）。它使用「深」字标、深墨绿侧栏、玉青交互色和浅矿物色内容区。`shenyi-brand.css` 排在平台 token 样式表之后，以语义别名完成映射，因此各功能仍继续使用既有主题词汇。

浏览器标题、PWA manifest、图标、启动页、侧栏、空白会话页、首次使用提示以及默认提供方／模型显示名称都使用新标识。模型路由 id、协议模型 id、包名、settings namespace、端点环境变量和协议行为保持不变；变更只作用于显示名称。

## 曾考虑的替代方案

只改文案而保留旧标志会让来源产品仍可一眼辨认，故不采用。改包名或协议标识会改动持久化配置和兼容性键，而非展示文本，故不采用。为每个页面单独覆盖颜色会偏离既有主题偏好，且让后续功能页风格不一致，故不采用。

## 后果

新的视觉层会一致地应用到现有的智能客服运营台和今后的设置页面。品牌工作应归入产品标识样式表和展示组件；除非另有明确的兼容性决策，服务标识保持稳定。

## 验证

重建受影响的客户端 bundle，运行 GUI 与 Web 快照验证，并在重启后的浏览器中检查运行页面。
