# Agent Note：TTS 故障时保持通话回复可见

Status: implemented

[English](2026-09-14-visible-call-replies-and-tts-fallback.md) | 中文

## Problem

通话字幕过去只在句子音频元素触发 `playing` 时增加内容。合成请求阻塞或失败时，即使模型回答已经进入持久化 Session，并能在挂断后显示，通话界面仍然没有回复文字。公司 MiniStream 服务可能先返回 `start`，之后不输出任何 MP3 帧，也可能用 429 拒绝实时容量。并发预加载下一句会占用更多有限容量。

## Decision

Session 中可见的临时或已提交助手文本更新时，通话控制器直接由其中的文本块生成客服字幕。电话界面会合并排版空白，并使已生成回答独立于播放状态保持可见。音频 `playing` 只改变通话状态，不再控制文字是否显示。

句子队列发送第一条 TTS 请求时不进行推测性预读。该句开始产生可听声音后，队列会在保持播放顺序的同时最多准备下一句。这样下一句的合成启动可与当前音频重叠，又不会同时打开多个尚未播放的实时请求。MiniStream 除完整流超时外，新增部署配置 `firstAudioTimeoutMs`；连接级 429 响应映射为 `PROVIDER_BUSY`。

通话配置可以指定首选 `synthesisProfile` 和可选 `fallbackSynthesisProfile`。Host 在不影响普通单提供方 Session 解析的情况下选择通话首选 profile，并向浏览器公布可用的降级 profile。合成或播放在句子产生可听声音前失败时，浏览器通过降级 profile 重试该句一次；降级播放成功后，同一次通话的后续句子和问题继续使用该 profile。音频开始后发生故障时不会重试，避免重复播放客户可能已经听到的内容。

澳门客服预设继续以公司 MiniStream 和 `mailinlin` 作为粤语首选路径，首帧超时为五秒。MiniStream 无法开始播放时，独立 Qwen3-TTS profile 分别以 Kiki、Cherry、Jennifer 和 Maia 提供粤语、普通话、英语和葡语。

## Alternatives considered

**仅让字幕与可听句子同步。** 否决，因为提供方失败会隐藏已经生成的答案，客户也无法判断模型是否完成该轮。

**首选提供方失败后结束该轮播报。** 否决，因为部署已经配置 Qwen 凭据和可用的流式提供方，而客户仍然期望听到回答。

**在当前句产生可听声音前准备下一句，或同时准备多条后续句子。** 否决，因为这会在当前提供方证明可用前打开实时生成请求，或让一条回答同时占用多个容量名额。单句预读只在当前音频可听后开始。

**部分播放后重试。** 否决，因为降级提供方会重复一段长度未知、客户可能已经听到的内容。

## Consequences

合成开始时，通话文字可能领先音频；这准确表示已生成内容，并在提供方异常时保持可用。一次通话中首选请求失败可能在首次降级播放前增加最多五秒等待，后续播报直接使用降级提供方。由可听事件触发的单句预读会消除大部分句间合成等待，并把每条回答的资源占用限制在当前音频加一条已准备句子。客户端测试覆盖立即显示生成字幕、可听事件触发的预读、开始播放前降级和跨问题复用；Host 测试覆盖显式首选 profile 与降级公布；MiniStream 测试覆盖首帧阻塞和容量分类。
