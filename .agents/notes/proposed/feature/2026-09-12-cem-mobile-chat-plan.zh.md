# Agent Note: 澳电手机 H5 聊天服务版开发说明与步骤

Status: proposed

[English](2026-09-12-cem-mobile-chat-plan.md) | 中文

## 问题

手机 H5 需要采用已选定的澳电方案 B：提供推荐提问、文字和语音输入，以及独立通话界面的客服聊天体验。会话连续性和 agent（智能体）选择仍需可用，但不向用户展示开发者设置。开发与验收期间，桌面应用、现有手机界面和独立客服页面都需要保持可用。

## 提案

在现有后端和客户端运行时上新增隔离的手机展示插件。[手机端包](../../../../packages/client/ui-mobile-chat/README.md)已实现 `/mobile.html?ui=cem-chat` 预览。提案继续保留，用于完成真机验收和默认手机入口切换；桌面、`/customer` 及默认旧手机入口保持可用。

### 已实现的预览与验收证据

预览包含推荐提问、真实流式聊天、Session 恢复与历史记录、客服 agent 选择、可编辑的语音转写，以及支持真实静音、手动打断和收起/恢复的独立通话页面。通过 `ctx.voiceRuntime` 访问共享语音实现，不复制传输代码。显式 id 的 Session 创建操作在查询语音配置前恢复休眠 agent，也适用于服务重启后，不伪造模型轮次。手机可以拒绝权限请求；授予系统操作权限仍在原应用的完整权限页面完成。

定向浏览器场景使用实际 Host 与客户端组合及回放提供方，覆盖草稿确认、通话清理、文字持久化和旧入口隔离。带凭证的部署检查另行验证真实 ASR 转写、开场白播放后的实时识别连接、模型回答和刷新恢复；MiniStream 真实 API 测试验证 MP3 合成。这些检查不证明安卓麦克风、扬声器、证书信任、声学回声、噪声误打断或后台暂停正常。默认入口切换仍等待真机验收。包级类型检查、构建和定向 lint 通过；仓库全量检查仍报告无关的既有问题和缺少 Git 元数据导致的失败。

[独立手机入口](../../implemented/architecture/2026-09-11-independent-mobile-web-entry.md)继续约定桌面与手机文档的隔离方式。[客服页面](../../implemented/feature/2026-09-12-cem-customer-conversation-portal.md)继续约定 `/customer`；它每次进入空白会话的策略不作为本次手机改版的策略。本提案不取代这两项决策。

### 范围与已核实的起点

| 领域 | 现有实现 | 手机方案 B 的目标 |
|---|---|---|
| 入口 | `/mobile.html` 带有 `data-dsh-mobile`，使用 MobileFrame；`/customer` 选择自己的根界面 | 新增仅手机端启用的根界面，提供明确的预览选择参数和旧版回退入口 |
| 对话 | 现有 Session 运行时提供提问、流式响应、取消和历史记录 | 以客服消息方式展示，保持同一份持久化记录 |
| Agent | 客服页面为空白 Session 选择 `macau-customer-service` | 新客服 Session 默认使用配置的客服预设；保留已有 Session 的 agent 归属 |
| 语音输入 | 语音控制器支持开始、停止、取消录音和转写 | 按住说话或无障碍点击录音，识别结果可编辑 |
| 通话 | 通话控制器支持开始/结束、阶段状态、字幕和语音合成回答 | 独立通话界面绑定当前 Session；补齐真实静音/手动打断能力后才宣称达到原型效果 |
| 品牌 | 客服页面引用远程 logo | 将用户提供的 CEM logo 的获准本地副本打包，橙红/黄色主题仅作用于手机 B 版 |

已核对的集成位置包括[手机入口](../../../../apps/web/mobile.html)、[布局注册](../../../../packages/client/ui-layout/src/client/index.ts)、[客服页面注册](../../../../packages/client/ui-customer-portal/src/client/index.ts)、[语音运行时工厂](../../../../packages/client/ui-voice/src/client/index.ts)和[通话控制器](../../../../packages/client/ui-voice/src/client/call.ts)。复用其公开运行时操作，不复制传输逻辑或组件内部订阅方式。

本期包括欢迎页、聊天、历史会话、服务 agent 选择、语音输入及浏览器内 AI（人工智能）通话。不包括方案 A、开发者设置、模型/密钥配置、更换后端、真实电话号码拨号或人工转接、账户/账单系统对接、录音存储、自动通话总结及生产环境认证改造。推荐问题只是对话起点，不表示已经接入账户查询或实际缴费能力。

### 页面与交互

**欢迎页。** 使用原始 CEM 标志、“澳電智能客服”标题、简短欢迎语、账单/缴费/停电/用电申请四类问题，以及醒目的“與澳電助手通話”卡片。历史记录和服务选择轻量放在顶部或抽屉中，不提供设置页。品牌界面使用适合澳门的繁体中文；工程文档维持英文/简体中文双语。

**聊天页。** 助手消息居左、用户消息居右，提供易读的流式文字、简洁时间和固定底部输入区。麦克风用于切换输入方式，电话按钮用于进入连续通话。提交失败保留草稿，提供重试并防止重复发送。“停止回答”仅取消所选 Session 的相应轮次。用户上滑阅读历史时停止自动滚动，显示“回到最新消息”。内部工具轨迹可以收起，但必要的授权确认和用户问题必须仍可处理。

**语音输入。** 展示“按住說話”、录音进度和“上滑取消”；处理触控取消事件，并提供等效的点击操作。松手结束录音，将识别文本放入可编辑草稿，由用户明确发送。这有意将原型中的“鬆開發送”改为识别后确认，便于纠正误识别。取消不提交任何内容；取消或切换 Session 后才返回的识别结果不能进入其他草稿。没有真实保留的音频源时，不展示可播放的语音气泡；首版消息以识别文字为准。

**通话页。** 展示“澳電語音助手”、接通后的计时、克制的品牌动效、真实通话阶段和易读的双方字幕。“返回聊天”缩小通话界面并保留持续可见的通话提示条，不结束通话；“結束通話”释放采集、识别与播放。重新打开界面不能创建第二路通话。聊天和通话共用一个 Session；已提交的文字在挂断后保留，识别中间结果及被取消的回答不能显示成已完成消息。

通话按钮包括静音、挂断和“我要說話”。共享控制器通过现有运行时服务提供 `setMuted` 和 `interrupt`；静音停止上传麦克风音频帧，手动打断停止本次回答并保留识别连接。既有调用方行为保持不变，不新增重复导出的语音工厂或传输实现。

通话页面将大部分可用高度留给当前字幕，状态圆环保持小尺寸，操作按钮固定显示。文字窗口底部对齐并裁切，在顶部渐隐超出的旧内容，不提供嵌套滚动条；长编号自动换行。聆听停顿期间保留当前文字，仅随共享控制器的当前话语与实际播报状态替换。按时间删除字幕会让阅读较慢的用户来不及读完，另建本地文本记录存储会重复 Session 的职责，因此都不引入。完整已提交消息仍可在聊天中查看。浏览器回归覆盖长回答、最新一行可见性、减少动态效果，以及窄屏、矮屏和横屏下的操作按钮；安卓实机显示仍待确认。

通话文字采用无边框的对话布局：客服靠左、用户靠右，使用小字号说话人名称，不添加字幕标题或消息气泡。用户要求的对话呈现保持独立于共享媒体实现。

触控目标至少 48 像素，适配安全区、软键盘/可视视口、字体缩放、清晰焦点、无障碍名称和减少动态效果偏好。颜色与动画辅助文字状态，不能独自承担状态含义。没有设备实测证据时，不承诺听筒/扬声器切换或锁屏后台通话。

### 版本隔离与文件归属

使用已有启动注入的 HTML 文档提供预览：`/mobile.html?ui=cem-chat`。这样无需新增尚未被[静态前端服务](../../../../packages/host/frontend-static/src/index.ts)注入启动配置的 HTML 入口。保留 `data-dsh-mobile`，确保继续选择手机专用的开场白播放适配器。

| 地址 | 开发期间 | 手机端验收后 |
|---|---|---|
| `/` 和 `/index.html` | 现有桌面版 | 不变 |
| `/customer` | 现有客服页面 | 不变 |
| `/mobile.html` | 现有手机版 | 明确切换后使用手机 B 版 |
| `/mobile.html?ui=cem-chat` | 手机 B 版预览 | 手机 B 版 |
| `/mobile.html?ui=legacy` | 现有手机版 | 现有手机版回退入口 |

新增经过校验、仅控制展示的插件选项，区分预览和默认启用模式；开发期默认预览。明确匹配手机路径及选择参数，拒绝不支持的配置值，不触碰其他路由。不按照浏览器标识自动重定向。查询参数只能选择展示方式，不能改变认证或权限。

插件负责界面、草稿、选择和手势状态；现有 Session/Workspace 服务负责对话数据，现有语音运行时负责媒体。通过 slot 及其标准存储/注入机制注册，清理由 effect 管理。组件接收普通视图数据和回调，不把客服页面中的运行时订阅方式复制到新展示组件内。

共享集成修改应限于 Web 组合/依赖注册、客户端构建配置，以及经过审查的语音控制器增量工作。桌面布局、旧 MobileFrame、`/customer` 组件、全局主题默认值、后端 API、持久化格式及现有语音预设值保持不变。展示冲突时优先复制隔离小型视图，不复制 Session/agent 运行时、ASR/TTS 传输逻辑或整个客服页面包。

按照 [Web 样式规范](../../../../docs/web-styling.md)，采用 CSS Modules 和限定在手机根元素内的语义主题覆盖。不添加无作用域的 `body`、共享按钮或桌面主题覆盖。手机专用标题/语言变更需要对应清理。仅给临时手机界面状态设置独立存储命名空间，不另建消息数据库或会话日志。

### Session、agent 与异常行为

进入时恢复仍然有效、可访问的最近客服 Session；否则展示欢迎状态，在操作需要时创建/选择获授权的空白 Session。重连后通过当前运行时校验保存的标识。不要沿用客服页面无条件进入新对话的行为，也不能静默改变已有非空 Session 的 agent。

通过现有 Workspace/Session 操作提供历史记录、新建对话和恢复已有对话。客服历史的前端筛选不是授权机制：不能仅因同一本地服务能列出运营会话，就向客户展示这些会话。公开部署前，真实的多客户隔离必须由后端身份与授权保障。

新 Session 默认使用配置的客服 agent。如果后端提供其他获准的服务 agent，则使用简洁的服务选择器，而非开发者设置。在进行中的对话里更换服务，确认后新建 Session；打开历史时保持该 Session 的 agent。agent 没有语音配置时隐藏不支持的语音操作并解释原因，文字对话保持可用。

录音、通话及其他音频播放互斥。通话中禁止切换 Session/agent，或先确认挂断并等待清理完成。离开页面释放媒体；重连不能自动重拨，也不能自动重发可能已被接受的提问。网络、权限、识别、合成与播放故障分别提供易懂提示、安全情况下的重试，以及文字聊天降级。保留同源 API 和已有授权，不在前端放提供方密钥，也不新增公网暴露。

### 实施步骤

1. **建立基线。** 确认选定的三屏设计，记录桌面/旧手机/客服页面的现有行为和已有测试失败。核对 Session 恢复、授权确认与语音生命周期操作，定义缺失的静音/打断 API 及其审查要求。交付入口隔离和能力核对清单。
2. **新增隔离界面。** 创建手机插件、组合注册、独立品牌资产/样式及预览选择参数。实现欢迎、空白/加载/异常状态、顶部、抽屉和响应式布局。交付可点击预览，默认手机地址仍显示旧界面。
3. **接入文字、Session 和 agent 流程。** 绑定真实 Session 投影、推荐提问、流式消息、取消、草稿恢复、历史记录和获授权的服务选择。保留授权确认与用户问题处理。交付导航和刷新后仍可连续使用的对话，不改变 agent，也不重复消息。
4. **接入语音输入。** 复用录音/转写控制器，增加按住/点击手势、取消、识别后确认、权限处理和文字降级。测试延迟授权及取消后才完成识别的情况。交付真实语音转文字，而非模拟录音。
5. **实现通话体验。** 复用当前 Session 的通话运行时，实现独立/缩小视图、阶段字幕、计时和挂断清理。实现经过审查的静音/手动打断操作，并覆盖旧调用方回归测试。VAD/噪声策略改动作为独立音频任务；界面改造本身不能修复误打断。交付可真实多轮通话、故障恢复清晰的版本。
6. **验证整机应用与真机。** 新增聚焦的单元/组件测试和不需要密钥的组装 Web 快照，再使用获准的现有凭据进行真实语音冒烟测试。覆盖 Android Chrome 和用户实际使用的安卓系统浏览器；宣称支持 iPhone Safari 前补充对应测试。记录截图与限制，覆盖外放、耳机、背景噪声、弱网和前后台切换。
7. **切换并保留回退。** 验收后仅切换手机展示选项，发布匹配的插件/前端构建产物并验证手机地址。保留旧版选择参数和上一版前端产物。回滚仅恢复展示/配置，不删除 Session、凭据、证书或历史记录。后续另行移除旧界面前，先明确回退支持周期。

应用读取构建后的客户端插件包，只重新构建 HTML/前端壳不足以更新插件。按照[客户端包规范](../../../../packages/client/AGENTS.md)和[测试策略](../../../../docs/testing.md)，先构建每个变更插件及前端，再进行组装验证。尽可能复用当前后端进程/配置；必要重启需安排执行，不能假定改了源文件就已更新运行中的网站。

## 考虑过的替代方案

**直接改共享桌面/手机组件样式。** 这会增加与桌面版的耦合，也不利于安全预览和回滚。保留现有布局，另行注册手机根界面。

**把手机用户直接指向 `/customer`。** 该路由可作为实现参考，但它每次新建 Session 的入口行为和现有设计不满足手机历史会话及选定的三屏交互。保留这个可独立使用的版本。

**新建完整的第二套前后端。** 独立服务和复制传输代码会增加部署与状态一致性工作，却没有对应的新增需求。隔离展示包，同时保留已有认证 API 和运行时。

**一开始就新增 HTML 文件。** 这需要同步修改启动注入、静态服务和构建配置。现有手机文档加明确预览选择参数即可隔离版本，无需改变服务端路由；只有分发需求确实需要时才重新考虑独立文档。

## 验收标准

- 桌面、`/customer` 和旧手机版保持原有外观与行为；手机 B 版之外不出现重复根界面、全局品牌样式污染、意外麦克风访问或语音默认值变化。
- 推荐提问和文字消息只向真实后端提交一次，回答流式易读，刷新后可从 Session 历史恢复，并支持取消/异常恢复。新建和恢复的 Session 使用正确 agent，必要授权确认仍可完成。
- 语音输入可录制、取消、转写和修改；识别失败不丢失文字草稿。取消或迟到的识别结果不会提交，不宣称提供不存在的录音回放。
- 通话支持多轮、真实状态/字幕、缩小/恢复、可用的静音/手动打断及挂断清理。已提交文字留在同一个 Session，切换或退出后不会继续播放旧音频。只有界面而没有真实控制能力，不算达到原型效果。
- 在 360、390、430 CSS 像素宽度下，字体缩放和软键盘不会遮挡消息或操作。实体安卓手机通过现有可信 HTTPS 入口完成语音输入及通话；其他浏览器只在验证后声明支持。
- 聚焦手机测试、旧版本回归测试和组装的无密钥快照覆盖变更行为。真实语音/设备结果与 mock（测试替身）测试分开报告；已有失败如实记录，不掩盖，也不越界修复。
- 演示默认入口切换及回退，不重置后端数据。服务重启保留现有部署配置和已记录的 Session。

## 风险

现有噪声误打断问题仍是独立的音频质量风险。手动打断提供控制权，但不能替代检测优化和设备测试；未解决的噪声表现必须体现在验收结果中。

即使 CSS 已隔离，共享语音控制器改动也可能影响其他版本。增量能力需显式启用并保留既有默认值；修改共享媒体逻辑时同时验证桌面、旧手机及客服页面的通话路径。需要新增公开 API 时，先审查再实施。

浏览器音频权限、播放策略、设备处理和后台挂起可能限制体验。现有部署仍需本地 HTTPS 信任和同源访问，视觉改版不会消除这些前提。公开部署需要独立评估身份、授权、隐私和运维就绪程度。

维持两个手机展示版本会增加维护成本。重复代码限于展示，后续单独决定旧版退场；替代版本还在评估时，不移除可用的回退入口。
